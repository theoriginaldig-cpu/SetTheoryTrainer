Set Theory Trainer

Practice questions about subsets, intersections and the like. Decide whether the conclusion follows. If it doesn’t, build a counterexample and the trainer will check it. Every question comes with a model answer.

Notation

Relations

A ⊆ Bevery member of A is a member of B
A ⊂ BA ⊆ B, and B has a member that is not in A (proper subset)
A ⊈ BA is not a subset of B: some member of A is not in B
A = BA and B have exactly the same members

Operations

A ∩ Bthings in both A and B
A ∪ Bthings in A or B (or both)
A − Bthings in A but not in B
∅the empty set

Predicates

{x: Fx}the set of things that are F
{x: Fx ∧ Gx}things that are both F and G
{x: Fx ∧ ¬Gx}things that are F but not G
{x: Fx ∨ Gx}things that are F or G

A counterexample is a small model in which all the premises are true and the conclusion is false. You build one by deciding which numbered objects belong to which sets. In the Predicates questions there must be at least one object.

Questions are generated at random. Every verdict is computed exactly, and every model answer is checked before it is shown.
